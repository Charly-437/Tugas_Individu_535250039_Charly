## Cara Menjalankan Project 
Jika Anda ingin menjalankan project Next.js (Tugas 9) di komputer lokal, ikuti langkah-langkah berikut:
1. Pastikan sudah menginstal **Node.js** di komputer.
2. Buka terminal (Command Prompt / VS Code Terminal) di dalam folder project **Tugas Pertemuan 9/kopi-nusantara-next**.
3. Jalankan perintah untuk menginstal dependensi:
   ```bash
   npm install
4. Setelah instalasi selesai, jalankan server pengembangan:
   ```bash
   npm run dev
6. Buka browser dan akses alamat yang muncul di terminal (biasanya http://localhost:3000).
